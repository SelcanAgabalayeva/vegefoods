# 🥦 VegeFoods - Organic Grocery E-Commerce Platform

VegeFoods is a modern full-stack grocery shopping web application developed for selling fresh fruits, vegetables, juices, dried foods, and other organic products online.

Inspired by the clean and minimal Vegefoods organic store template, this project transforms the frontend design into a powerful backend-driven enterprise-level e-commerce system using Spring Boot ecosystem.

The platform allows customers to browse products, manage shopping carts, place secure orders, make online payments, and track deliveries, while administrators can manage inventory, categories, orders, discounts, and customer data.

---

## 🚀 Project Features

### 👤 Customer Side
- User Registration & Login
- Spring Security Authentication
- Browse Products by Categories
- Product Search & Filtering
- Product Detail Page
- Shopping Cart Management
- Wishlist Support
- Checkout System
- Stripe Payment Integration
- Newsletter Subscription
- Contact & Feedback Form

---

### 🛠 Admin Panel
- Secure Admin Dashboard
- Manage Categories
- Manage Products
- Manage Customer Orders
- Apply Discounts & Coupons
- User Management
